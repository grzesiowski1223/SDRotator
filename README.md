# SDRotator
Satellite Dish mount using ESP32-S3 Devboard

# Features
> [!WARNING]
> Since I don't have any motors and motor controllers at this point, well SDRotator doesn't have motor control and tracking (for now)

- Fetching Azimuth and Elevation of the satellite
- WiFi NTP syncing 
- CPU Overheat Protection
- Basic Command Line User Inteface
